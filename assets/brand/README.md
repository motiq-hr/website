# Motiq logo — M + hvataljka

Odabrani koncept 02, potvrđen 4.10.2026. Znak povezuje slovo M i dvije robotske hvataljke; unutarnji rezovi podsjećaju na motiku. Tipografija je nacrtana kao geometrijski oblik, bez vanjskog fonta.

**Izvor geometrije:** `master.json` u ovom repozitoriju. SVG i PNG su izvedene datoteke. Promjene se rade ovdje pa ponovno izvoze s `npm ci && npm run brand:build`. GitHub Pages poslužuje ih pod `https://www.motiq.biz/assets/brand/`.

| Datoteka | Namjena |
| --- | --- |
| `motiq-horizontal.svg` / `.png` | Glavni logo za svijetlu podlogu; PNG ima prozirnu pozadinu |
| `motiq-reversed.svg` / `.png` | Bijeli logo za tamnu podlogu |
| `motiq-black.svg` / `.png` | Jednobojni crni tisak |
| `motiq-forest.svg` / `.png` | Zelena verzija, #1E3A2E |
| `motiq-icon*.svg` | Samostalni znak |
| `motiq-stacked.svg` / `.png` | Uspravni raspored |
| `app-icon*`, `favicon*` | Web, aplikacije i Notion |

Ostavi slobodan prostor oko znaka najmanje koliko iznosi srednji razmak između dviju polovica. Čuvaj omjer širine i visine; za male kvadratne ikone koristi znak bez naziva. Bez sjena, gradijenata ili dodatnog okvira. Glavni horizontalni logo preporučuje se od 112 CSS px širine; za manje koristi ikonu.

Izvorni generirani koncept čuva se u lokalnom/Drive paketu kao referenca. SVG je ručno uređena vektorska izvedba odabranog smjera, pa raster koncept nije precizan proizvodni nacrt.
